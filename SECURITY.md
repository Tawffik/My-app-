# Security Policy

## Purpose

CyberOS is an educational and personal research tool. Use it only against systems you own or are explicitly authorized to test.

## Reporting issues in this project

If you find a vulnerability in CyberOS itself (e.g. unsafe handling of stored data, cleartext secrets), open a private report to the repository owner or a GitHub security advisory if enabled.

## Design expectations

- No production API keys in source control  
- External web content is untrusted  
- AI responses are not proof of vulnerability  
- Notification and network permissions are used for research sync and local digests only  

## Responsible AI use

Do not use AI modes to generate attacks against unauthorized targets. Prefer local labs and public learning materials.
