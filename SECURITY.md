# Security Policy

## Purpose

CyberOS is an educational and personal research tool.  
Use it only against systems you **own** or are **explicitly authorized** to test.

## Reporting issues in this project

If you find a vulnerability in CyberOS itself, contact the repository owner or open a private GitHub security advisory if enabled.

## Design expectations

- No production API keys in source control  
- External web content is untrusted  
- AI responses are not proof of vulnerability  
- Network/notification permissions support research sync and local digests only  

## Responsible AI use

Do not use AI modes against unauthorized targets. Prefer local labs and public learning materials.
